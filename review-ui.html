反馈如何进入流水线

  1. 在上方队列里点选标签（有用 / 重要 / 噪声 / 不相关 / 有误 / 已处理），或把事件加入某个 watchlist 跟踪。
  2. 操作先落本机浏览器（localStorage），不会自动写回仓库——静态站点没有后端，这一步必须诚实。
  3. 点「导出 JSON」下载 p2_feedback_export.json，或点「提交 GitHub Issue」把同一份负载贴进 Issue（自动加 复核反馈 标签）。
  4. 在本地或 CI 执行 python3 p2_import_feedback.py p2_feedback_export.json：脚本逐行校验标签 / 状态 / 评分 / 时间戳，非法行拒绝入库并给出原因，通过后合并写入 p2_state.json。
  5. 重跑 p2_intelligence.py 后，标为「已同步」的记录才会参与排序加成与噪声抑制。
样本量门槛：反馈样本 < 30 时，系统不得出任何偏好结论，只记录事实。这是刻意的保守设定。
